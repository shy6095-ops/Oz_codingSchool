콘솔창 사칙연산 계산기

실행 방법

Windows : F12 → Console 탭 → start() 입력 후 Enter

Mac : Option + Command + I → Console 탭 → start() 입력 후 Enter

입력 규칙

  • 숫자와 연산자는 공백으로 구분합니다. 예) 3 + 5 * 2
  • 사용 가능한 연산자: + - * /
  • * / 를 먼저 계산합니다. (연산자 우선순위 적용)
  • 0으로 나누면 에러 메시지를 출력합니다.
  • 계산 후 "계속 계산하시겠습니까?"에서 취소를 누르면 종료됩니다.

테스트

콘솔에서 runTests() 를 입력하면 준비된 예제로 자동 검증합니다.

예제: 3 + 5 * 2 → 13, 10 / 2 - 1 → 4, 2 * 3 * 4 → 24
