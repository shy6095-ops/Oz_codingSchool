# 6일차_폐렴예측_API_설계.md

## AI 폐렴 예측 사용자 요구사항 정의서

| 요구사항 ID | 기능 요약 | 기능 상세 | 구분 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| REQ-PRED-001 | AI 모델 활용 폐렴 예측 | - 사내 의료인, 개발팀, 연구자 권한을 가진 유저는 진료기록 상세 페이지에서 `AI 예측 결과보기` 버튼을 클릭하여 폐렴 예측 모델을 활용한 예측결과를 확인할 수 있어야 한다.<br>- 폐렴 예측 시 필요한 X-ray 이미지는 진료기록 저장 시 업로드한 이미지를 활용한다.<br>- 이미 해당 진료기록으로 같은 모델을 사용하여 저장된 예측 결과가 있다면 별도로 AI 추론 과정을 거치지 않고 저장되어 있던 데이터를 응답한다.<br>- AI 예측 결과 섹션에서 바로 확인할 수 있도록 한다.<br><br>**결과 데이터**<br>• 폐렴 여부 (True, False)<br>• Confidence<br>• Hitmap Image URL (선택사항) | 기능 | |
| REQ-PRED-002 | AI 모델 활용 폐렴 예측 결과 조회 | - 사내 의료인, 개발팀, 연구자 권한을 가진 유저는 진료기록 상세 페이지의 AI 예측 결과 섹션에서 해당 환자의 흉부 X-Ray 사진과 폐렴 예측 모델을 활용한 예측결과를 목록으로 확인할 수 있어야 한다.<br><br>**목록에서 확인 가능한 필드 항목**<br>• 고유 ID<br>• 폐렴 여부<br>• Confidence<br>• Hitmap Image URL<br>• 예측 수행 일시<br>• 사용한 모델 | 기능 | |
| NFR-PRED-001 | AI 모델 평가 기준 | **오차 행렬 (Confusion Matrix)**<br>- **TP**: 폐렴환자를 폐렴으로 진단<br>- **FP**: 정상인이지만 폐렴으로 오진<br>- **FN**: 폐렴 환자인데 정상으로 오진 (⚠️ 가장 위험)<br>- **TN**: 정상인임을 진단<br><br>**평가 지표**<br>• **Recall (민감도) ≥ 0.90 ~ 0.95 (최소 0.90)**<br>  - "실제 폐렴 환자를 얼마나 놓치지 않는가"에 대한 기준<br>  - 계산식: TP / (TP + FN)<br>• **Accuracy ≥ 0.80 ~ 0.90 (보조 지표)**<br>  - 모델 예측 정확도<br>  - 계산식: (TP + TN) / 전체 표본 수 | 비기능 | |
| NFR-PRED-002 | API 성능 | 모든 API는 3초 이내에 응답하여야 한다. | 비기능 | |
