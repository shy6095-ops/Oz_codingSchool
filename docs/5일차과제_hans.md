# 환자 관리 및 진료기록 시스템 요구사항 정의서 (Requirements Specification)

## 1. 개요 (Overview)
본 문서는 환자 관리 및 진료기록 관리 시스템 구축을 위해 작성된 요구사항 정의서입니다. 본 요구사항을 바탕으로 5일차 환자 관리 API 설계 및 구현을 진행합니다.

---

## 2. 기능 요구사항 (Functional Requirements)

### 2.1 환자 관리 (Patient Management - PTNT)

| 요구사항 ID | 기능 요약 | 기능 상세 | 구분 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **REQ-PTNT-001** | 환자 정보 등록 | • **권한**: 사내 의료인<br>• **접근**: 환자 관리 메뉴 → '환자 정보 등록' 버튼 → 모달<br>• **필수 입력 항목**: 이름, 나이, 성별, 연락처(휴대폰 번호) | 기능 | 모달을 통한 등록 처리 |
| **REQ-PTNT-002** | 환자 목록 조회 | • **권한**: 사내 개발진, 의료 실무진, 연구진<br>• **검색**: 이름 기준 검색 제공<br>• **필터링**: 성별, 나이 범위 기준 필터링 제공<br>• **조회 필드**: 환자 고유 ID, 이름, 나이, 성별, 연락처, 생성일시, 수정일시 | 기능 | 검색 및 필터링 기능 포함 |
| **REQ-PTNT-003** | 환자 정보 상세 조회 | • **권한**: 사내 개발진, 의료 실무진, 연구진<br>• **접근**: 환자 목록 항목 우측 '상세보기' 버튼 → 상세 페이지 이동<br>• **확인 항목**: 이름, 성별, 연락처, 나이 | 기능 | 상세 페이지 이동 및 데이터 표출 |
| **REQ-PTNT-004** | 환자 정보 수정 | • **권한**: 사내 개발진, 의료 실무진, 연구진<br>• **접근**: 상세보기 페이지 우측 상단 '정보 수정' 버튼 → 모달<br>• **수정 가능 항목**: 이름, 연락처 | 기능 | 모달을 통한 수정 처리 |
| **REQ-PTNT-005** | 환자 정보 삭제 | • **권한**: 사내 개발진, 의료 실무진, 연구진<br>• **접근**: 상세보기 페이지 우측 상단 '삭제' 버튼 → 확인 팝업 모달<br>• **상세**: '확인했습니다' 클릭 시 관련 진료기록 및 X-Ray 이미지 함께 영구 삭제 | 기능 | Cascade 삭제 (진료기록/이미지 포함) |

### 2.2 진료기록 관리 (Medical Record - MDR)

| 요구사항 ID | 기능 요약 | 기능 상세 | 구분 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **REQ-MDR-001** | 진료기록 등록 | • **권한**: 사내 의료인<br>• **접근**: 환자 상세 페이지 내 진료기록 목록 섹션 우측 상단 '진료기록 등록' 버튼 → 등록 페이지<br>• **필수 입력 항목**:<br>&nbsp;&nbsp;- 환자 정보 (고유 ID)<br>&nbsp;&nbsp;- 진료 차트 넘버<br>&nbsp;&nbsp;- 진료된 증상<br>&nbsp;&nbsp;- 흉부 X-Ray 이미지 (업로드 시 미리보기 제공) | 기능 | 이미지 저장 경로: 서버 로컬 저장소 |
| **REQ-MDR-002** | 진료기록 목록 조회 | • **권한**: 사내 개발진, 의료 실무진, 연구진<br>• **접근**: 환자 상세 정보 페이지 내 진료기록 목록 섹션<br>• **조회 필드**: 진료 기록 ID, 진료 차트 넘버, 증상 (100자 초과 시 … 생략), 생성일시 | 기능 | 증상 100자 초과 시 생략 처리 |
| **REQ-MDR-003** | 진료기록 상세 조회 | • **권한**: 사내 개발진, 의료 실무진, 연구진<br>• **접근**: 환자 상세 정보 페이지 내 진료기록 항목 우측 '상세보기' 버튼 → 상세 페이지<br>• **조회 필드**: 진료 기록 ID, 차트 넘버, 증상, 흉부 X-Ray 이미지, 생성일시 | 기능 | 상세 페이지 이동 및 이미지 표시 |

## 3. 비기능 요구사항 (Non-Functional Requirements)

| 요구사항 ID | 영역 | 요구사항 상세 | 구분 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **NFR-PTNT-001** | API 성능 | 모든 환자 관리 유저 API는 최대 3초 이내에 로직을 처리하고 응답하도록 한다. | 비기능 | 응답시간 ≤ 3초 |
| **NFR-MDR-001** | API 성능 | 모든 진료기록 유저 API는 최대 3초 이내에 로직을 처리하고 응답하도록 한다. | 비기능 | 응답시간 ≤ 3초 |

## 4. API 설계 연결 프레임워크 (5일차 환자 관리 API 설계 구조 참고)

| 분류 | Endpoint | Method | 요청자 권한 | 주요 처리 내용 |
| :--- | :--- | :--- | :--- | :--- |
| **환자 등록** | `/api/v1/patients` | `POST` | 사내 의료인 | 필수값 검증 (이름, 나이, 성별, 연락처) 후 생성 |
| **환자 목록 조회** | `/api/v1/patients` | `GET` | 개발진 / 실무진 / 연구진 | 이름 검색 (`name`), 성별 필터 (`gender`), 나이 범위 (`minAge`, `maxAge`) |
| **환자 상세 조회** | `/api/v1/patients/{patientId}` | `GET` | 개발진 / 실무진 / 연구진 | 환자 기본 정보 반환 |
| **환자 정보 수정** | `/api/v1/patients/{patientId}` | `PATCH` / `PUT` | 개발진 / 실무진 / 연구진 | 이름, 연락처 수정 |
| **환자 정보 삭제** | `/api/v1/patients/{patientId}` | `DELETE` | 개발진 / 실무진 / 연구진 | 환자 데이터 및 하위 진료기록, X-Ray 파일 영구 삭제 |
| **진료기록 등록** | `/api/v1/patients/{patientId}/medical-records` | `POST` | 사내 의료인 | `multipart/form-data` (차트번호, 증상, X-Ray 파일 업로드) |
| **진료기록 목록 조회** | `/api/v1/patients/{patientId}/medical-records` | `GET` | 개발진 / 실무진 / 연구진 | 증상 100자 축약 처리하여 목록 반환 |
| **진료기록 상세 조회** | `/api/v1/medical-records/{recordId}` | `GET` | 개발진 / 실무진 / 연구진 | 진료 기록 및 X-Ray 이미지 파일 경로/URL 반환 |
