# 9일차 아키텍처 도식

- `architecture.excalidraw` — Excalidraw 소스. https://excalidraw.com 에서 **Open** 으로 열어 위치/문구를 다듬은 뒤 PNG 로 내보낸다.
- `01_architecture_excalidraw.png` — 위 소스를 내보낸 캡처 이미지. `docs/9일차_동시성문제_해결을위한_아키텍처설계.md` 6절에서 이 파일을 참조한다.

## 내보내기 순서
1. excalidraw.com → 좌상단 메뉴 → **Open** → `architecture.excalidraw` 선택
2. 배치/줄바꿈 정리 (특히 화살표가 박스에 안 붙어 있으면 끝점을 살짝 끌어 스냅)
3. 메뉴 → **Export image** → PNG, 배경 켜기(흰색), 2x → 저장
4. 저장 파일명을 `01_architecture_excalidraw.png` 로 하여 이 폴더에 둔다
